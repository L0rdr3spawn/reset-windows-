Wenn der User vom „GeoGuessr-Ding“ spricht, ist der Geofinder gemeint: `C:\Users\reiss\Documents\claude\geofinder\`
(Dienst `geofinder.py`, Karte http://127.0.0.1:8777). Ausführliche Notizen stehen in der Memory des Projekts
`C--Users-reiss-Documents-claude` (geofinder.md), dort auch die Betriebsfallen (LM-Studio-Server, Neustart nach Python-Änderungen).
