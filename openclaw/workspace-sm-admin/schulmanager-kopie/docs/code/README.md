# Code-Doku (extern)

Die Entwickler-Code-Doku (frühere Bereichsdateien 01 bis 09) wird nicht mehr im Repository gepflegt, damit sie nicht
zusammen mit dem Quelltext verteilt wird. Sie liegt im externen Schulpuls-Atlas außerhalb dieses Repos
(`schulpuls-atlas/`, Einstieg `INDEX.md`, Generator `atlas.py`).

Kundendokumentation (Installation, Betrieb, Hilfe, Datenschutz-Vorlagen) bleibt unter `docs/`.
