# Kurzanleitung für Eltern

Diese Anleitung zeigt, wie Sie als Eltern die wichtigsten Dinge erledigen. Sie sehen nur Daten Ihrer eigenen Kinder.

## Anmelden
1. Öffnen Sie die Adresse Ihrer Schule im Browser (am Handy lässt sich die Seite wie eine App zum Startbildschirm hinzufügen).
2. Geben Sie Benutzername und Startpasswort aus dem Zugangsbrief ein. Der Brief enthält auch einen QR-Code zur Anmeldeseite.
3. Beim ersten Anmelden vergeben Sie ein eigenes Passwort. Wählen Sie mindestens 10 Zeichen und verwenden Sie es nirgendwo sonst.
4. Passwort vergessen? Auf der Anmeldeseite „Passwort vergessen“ wählen. Sie bekommen einen Link per E-Mail, sofern Ihre Adresse hinterlegt ist; sonst hilft das Sekretariat.

## Stundenplan und Vertretung
- Unter **Stundenplan** sehen Sie die Woche Ihres Kindes. Mehrere Kinder wählen Sie oben aus.
- Entfall, Vertretung und Raumwechsel erscheinen direkt im Stundenplan. Geänderte Stunden sind farbig markiert.
- Unter **Klausuren** stehen angekündigte Klassenarbeiten und Tests.

## Krankmeldung
1. Öffnen Sie **Krankmeldungen** (oder den Knopf „Krank melden“ auf der Startseite).
2. Wählen Sie das Kind, den ersten und letzten Fehltag und tragen Sie einen kurzen Hinweis ein.
3. Senden Sie die Meldung ab. Die Schule sieht sie sofort. Ab einer bestimmten Dauer ist ein Attest nötig; die Schule teilt Ihnen mit, ab wann.
4. Ein Attest laden Sie unter **Atteste und Dokumente** hoch (Foto oder PDF).

Bitte melden Sie Ihr Kind möglichst vor Unterrichtsbeginn. Die telefonische Erreichbarkeit des Sekretariats steht auf der Krankmeldeseite.

## Nachrichten
- Unter **Nachrichten** schreiben Sie Lehrkräften, dem Sekretariat und der Klassenleitung. Antworten kommen dorthin und, wenn Sie das wünschen, zusätzlich per E-Mail.
- Elternbriefe der Schule mit Rückmeldung („gelesen“, „einverstanden“) erscheinen ebenfalls hier und unter **Formulare**.
- Unter **Benachrichtigungen** im Profil stellen Sie ein, worüber Sie informiert werden möchten (E-Mail, Zusammenfassung, Ruhezeiten).

## Lernstand und Noten
Wenn die Schule es freigibt, finden Sie Rückmeldungen zum Lernen unter **Lernstand** und Noten unter **Noten**. Noten sehen Sie erst, wenn die Lehrkraft sie freigegeben hat.

## Ihre Daten
- Unter **Datenschutz** sehen Sie, welche Daten über Ihr Kind gespeichert sind, und können Auskunft anfordern.
- Zwei-Faktor-Anmeldung (Authenticator-App) schützt Ihr Konto zusätzlich: Profil, Abschnitt „Sicherheit“.
- Fragen zum Datenschutz richten Sie an die Datenschutzbeauftragte bzw. den Datenschutzbeauftragten der Schule.
