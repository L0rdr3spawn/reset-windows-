# Anhang: Rohmaterial zum Nachschlagen

Die **Hauptdateien im Ordner `paket/` gehen vor**. Der Anhang enthält die Rohnotizen, aus denen sie entstanden sind. Er ist umfangreicher und enthält Wiederholungen sowie gelegentlich überholte Stände. Lies ihn nicht am Stück, sondern schlage gezielt nach (Suche nach Begriff, Tabellenname, Recht, `SM_*`-Variable). Bei Widerspruch zu einer Hauptdatei gilt die Hauptdatei. Kein Anhang enthält Zugangsdaten, Schlüssel, echte Adressen oder Personennamen.

## zahlen-und-tabellen/ (konkrete Werte, vollständig)
| Datei | Inhalt |
|---|---|
| Z1 | Rechtekatalog: alle Rechte, Rollen, Datenumfänge, Standardzuordnung |
| Z2 | Konfiguration und Anmeldung: alle `SM_*`-Variablen mit Standards, Drosselung, Sitzungen, Passwortregeln |
| Z3 | Löschfristen, Verschlüsselung je Feld, Wartungsjobs, Protokolle |
| Z4 | Lizenz, Updates, Zahlungen, Anbieter-Server |
| Z5 | Generator-Werte, Vertretung, Noten, Fehlzeiten (Formeln, Gewichte, Grenzen) |
| Z6a, Z6b, Z6c | Datenbank: alle Tabellen mit allen Spalten (a–f, g–p, q–z) |
| Z7 | Planungsdokument (Stundenplan-Entwurf): Aufbau, Felder, Versionierung |
| Z9 | Oberflächen: Seiten, Bausteine, Tokens, Menü |

## ist-zustand/ (was das Altsystem kann, je Fachbereich)
I1 bis I15 (u. a. I4 Anmeldung, I8 Betrieb/Tabellen, I9 Architektur, I10 Datenschutz-Dokumentation, I11 Betriebshandbuch, I12 Design und Handbuch, I13 Updates/Lizenz/API/Import, **I15 alle 716 API-Endpunkte** nach Zweck).
